# Signal Bloom

Signal Bloom is a midnight-neon library theme for Hollycast. It uses the
official Hollycast banner in the compact toolbar, dark scanline backdrops,
cyan selection outlines and coral launch controls.

The selected game's fanart fills the background with a dark navy wash for
readability. A scraped screenshot appears when fanart is absent; when neither
exists, the original Bloom artwork remains. These images come from the local
library and are not redistributed in the theme package.

The package provides a cover gallery, an alternate list layout and a portrait
list layout. Each game uses one cover-art slot. The selected game's title,
release date and description come from library metadata. No game art, screenshots,
fan art, manuals, discs or game logos are included.

## Install

Open Settings > Library > Browse themes, choose Signal Bloom, then select
Download and install and Use theme.

To install the ZIP manually, extract it into a folder named signal-bloom so
theme.json is directly inside that folder. Copy the folder into library-themes
under the data directory used by Hollycast, then reload Library Themes.

## Rebuild

Run python source/build_theme.py from this folder. The deterministic ZIP is
written beside the package. The manifest is generated by that script.

Compatibility: requires the renderer support on nexus382/Hollycast branch
`codex/play-archive-signal-bloom`. Older releases cannot load these extensions.
Restart Hollycast after changing themes to refresh the theme fonts.
